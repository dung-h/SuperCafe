# OpenClaw Telegram Sales Bot (MVP)

MVP bot Telegram ho tro kinh doanh:
- Listing san pham, chi tiet san pham.
- Phan loai danh muc do uong (coffee, milk_tea, fruit_tea, juice, other).
- Tao don, theo doi don, xu ly thanh toan chuyen khoan thu cong.
- Quan tri don hang + ton kho qua lenh admin Telegram.
- Telegram Mini App co anh san pham, gio hang 3 buoc (chon mon -> xac nhan gio -> thanh toan) de tang ty le chot don.
- AI hoi dap san pham qua `openclaw` service dung model API key (OpenAI-compatible `chat/completions`).

Tai lieu van hanh: `docs/runbook.md`
Hop dong API: `docs/api-contract.md`
